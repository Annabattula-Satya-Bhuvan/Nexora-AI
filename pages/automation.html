How a workflow is organized

A workflow template describes a trigger, an ordered sequence of agent tasks, and an expected result.

01 Trigger — event or schedule
02 Planning Agent — break down the task
03 Specialist Agent — perform assigned work
04 Verification Agent — review the result
05 Human approval — when required

Execution model

This page saves workflow definitions in your browser. It does not schedule background jobs or execute agents. Real triggers, scheduling, orchestration and execution will be connected through the NEXORA backend.
